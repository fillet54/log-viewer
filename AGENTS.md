# Event Log Viewer Project Instructions

## Frontend Tooling Constraints

- Do not introduce npm, Node package managers, `package.json`, `node_modules`, or `shadow-cljs`.
- Keep ClojureScript builds on Clojure CLI / `cljs.main` or other JVM/Clojure-only tooling unless the user explicitly changes this constraint.
- When adding Replicant, Portfolio, tests, or other frontend tooling, choose dependencies and workflows that work without npm and without `shadow-cljs`.
